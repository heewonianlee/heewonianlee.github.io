# An HLS-Based Audio CNN Accelerator for the Kria KV260

## [Vivado Block Design]({% link kv260-block-design.md %})

## Summary

At Michigan State University's HATLab, I designed a CNN accelerator on Kria KV260 for on-device speaker verification. I implemented the datapath in Vitis HLS and integrated it with the Zynq processing system in Vivado. 

## [Reference]({% link kv260-reference.md %})

I used a published KV260 audio CNN as a latency benchmark. The reference page describes the paper's DPU implementation and how I compared it with my design.

## [Optimizations]({% link kv260-optimizations.md %})

I used two lanes in Block 1 and reused MAC lanes across two phases in Block 3. The optimizations page explains how streaming activations, banking weights, and choosing arithmetic widths supported those decisions.

## Results

| One CNN inference at 100 MHz | HLS estimate | Vivado RTL simulation |
| --- | ---: | ---: |
| Total latency | 2.963 ms | 5.969 ms |
| Weight and bias loading | 0.763 ms | 3.434 ms |
| Compute pipeline | 2.200 ms | 2.535 ms |

Parameter loading accounted for about 89% of the gap between estimated and simulated latency. This makes the weight and bias transfer path my first target for further optimization.
